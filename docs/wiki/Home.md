# Hi WPEssential documentation

Hi WPEssential is a multi-niche WordPress block theme. It is native for Gutenberg, Elementor and WooCommerce, and its demos are built from the WPEssential kit.

| Page | What it covers |
| --- | --- |
| [Site Settings](Site-Settings) | Global colours, fonts, buttons, forms, layout and motion in **Appearance → Site Settings**. |
| [Controls](Controls) | The Elementor-style controls (colour, responsive slider, dimensions, typography, box shadow, gradient, background…). Shows how to reuse them in any settings screen. |
| [Google Fonts](Google-Fonts) | How the 1,700+ Google Fonts are offered, downloaded to the site and shown in the editors. |
| [Page settings](Page-Settings) | Per page / post options in Gutenberg and Elementor. |
| [Kit elements](Kit-Elements) | The WPEssential elements (Heading, Text, Button, Image, Icon list…) and the Elements screen. |

These pages live in the theme repository under `docs/wiki/`. A GitHub Action copies them to the repository wiki on every change to `main`.
