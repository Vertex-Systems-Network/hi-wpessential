# Kit elements

The kit elements are part of the WPEssential plugins, not this theme. Their documentation and the element status are in the plugin repository: [`docs/KIT-ELEMENTS.md`](https://github.com/Vertex-Systems-Network/wpessential/blob/main/docs/KIT-ELEMENTS.md).

This theme only styles the elements, through `theme.json`, style variations and the Site Settings.
