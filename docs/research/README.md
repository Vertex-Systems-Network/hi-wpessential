# R&D process for every demo

Owner instruction (Oct 2026): study the best-selling themes, keep three banks up to date, design only from
the banks, then compare against the market and redo anything that is not better.

**Themes studied:** Avada (113 prebuilt sites, 450+ Studio blocks), Betheme (700+ prebuilt sites, 19 categories),
Enfold, The7, WoodMart, Shopkeeper, Newspaper (tagDiv), plus the ThemeForest WordPress best-sellers list
(themeforest.net/popular_item/by_category?category=wordpress).

## Steps
1. **Research** – open the niche's demos in the themes above + 3–5 real market leaders; list every page, section and element.
2. **Bank it** – add anything new to:
   - [elements-bank.md](elements-bank.md) – atomic UI parts (buttons, badges, cards, counters…)
   - [sections-bank.md](sections-bank.md) – page sections and their variants
   - [niche-bank.md](niche-bank.md) – per niche: pages, must-have sections, plugins, tone
3. **Design** – build the Figma pages only from bank items (sections + elements) that the niche bank marks as required/recommended, following [../demos/design-rules.md](../demos/design-rules.md).
4. **Compare** – score our demo vs the 3 strongest competitor demos on the scorecard below.
5. **Iterate** – if we are not equal or better on every row, redesign those parts and score again.
6. **Build** – only then build Gutenberg + Elementor packages.

## Scorecard (1–5 per row; ours must be ≥ best competitor on every row)
| Criterion | What we check |
| --- | --- |
| First impression | hero quality, typography scale, photography, motion hint |
| Section variety | number of distinct section types on home, no repeated card grids |
| Niche fit | every must-have section/page from the niche bank present |
| Conversion | clear primary CTA, secondary CTA, proof near CTAs, forms |
| Content depth | inner pages (detail, archive, contact with map, legal) |
| Mobile | 360 layouts designed, not just stacked |
| Woo / plugins | shop, cart, booking, LMS or events integrations where the niche needs them |
| Performance | no heavy sliders, local fonts, image sizes |
